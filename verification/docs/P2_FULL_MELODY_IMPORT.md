## 已完成的输入工具

`tools/import_p2_melody_midi.py` 用 Python 标准库读取用户提供的 SMF 0/1 MIDI，
选择明确的一条主旋律轨道/通道，转换为现有 P2 96 bit 事件和 16 byte 传输记录。
不连接设备，不写入生产 ROM、目录或 INIT，不自动启动综合/布线。

- 保留全部所选音符、原始分数拍节奏、开头/结尾休止。不会自动循环、漏音、移八度或截短音符。
- 固定每分钟 60 个四分音符；原 MIDI 的变速事件写入清单，不应用到此慢练版。
  起音和结束分别用有理数精确换算至 48 kHz 整数样本，避免累计舍入漂移。
- 默认第二音色与现有固定力度编码 2；原 MIDI 音色/力度不覆盖硬件设置。
- 延用已有分弦分配器及同弦不重叠、临近音优先换弦规则。
  过密、超时长、超容量、音域不符均报错，不删音以获得通过。
- 多条候选旋律不猜选；通过 `--inspect` 列出轨道和通道，编号均从 0 开始。
  排除打击乐通道；和弦/重叠旋律、未配对 Note On/Off、非中心弯音、延音踏板及 SysEx 要求先整理输入。
- 整体移调只有显式 `--transpose` 才生效；不符 D3～C5 时报告可用移调范围。
  接入具体歌曲前先审阅是否需要整体移调，不自动改变用户指定旋律。
- 输出 `.csv`、`.mem`、`.bin`、`.json` 到新的前缀；既有输出不覆盖。
  清单绑定输入 SHA256、轨道、节奏、移调、音色、事件数、总时长、CRC32 和输出哈希。

用法（输入文件尚待提供，以下不是已完成《情歌》导入的记录）：

```powershell
E:/anaconda3/python.exe tools/import_p2_melody_midi.py my_melody.mid --inspect
# 轨道/通道按上一步实际列出的主旋律选择
E:/anaconda3/python.exe tools/import_p2_melody_midi.py my_melody.mid build/p2_full_melody/qing_ge --track 1 --channel 0 --bpm 60 --timbre 1 --title "情歌完整主旋律"
E:/anaconda3/python.exe tools/test_import_p2_melody_midi.py -v
```

输入若为完整简谱/五线谱，可先人工核对音高、拍号、反复、休止和连音，转成既有分数拍 CSV。
无需先有 MIDI；不能只凭和弦名称推断出原歌的完整主旋律。

格式参考：[MIDI Association 的 SMF 规范](https://midi.org/standard-midi-files-specification)，
[Mido 官方 SMF 文档](https://mido.github.io/mido/files/midi.html)。本工具不依赖 Mido 或联网安装。
