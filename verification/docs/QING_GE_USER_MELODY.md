# 《情歌》用户谱完整主旋律试奏版

2026-10-18：当前主工程已由[P3可写曲库/UART发布](P3_WRITABLE_SONG_IMPORT.md)更新。本页M2资源、位流哈希和验证只认证固定主旋律历史归档；同一38小节/212起音内容、第二音色及用户暂接受的第10/18小节时值继续保留在P3。当前原`impl`应使用P3认证，不能套用本页旧日志。

## 本次内容与明确许可

输入为用户于 2026-10-16 提供的两张 EOP / Wuyangr 双行钢琴简谱图片，原谱 G 调、4/4、72 BPM。
保留原图和哈希于 `scores/p2/source/qing_ge_user_page_1.jpg`、`qing_ge_user_page_2.jpg`，
逐音读谱记录在同目录 `qing_ge_user_melody.json`，生成的逐音审计在 `scores/p2/qing_ge_transcription_audit.json`。

本版取上行主旋律，覆盖图片全部 **38 小节／152 个四分音符拍**；按已选慢练速度 **60 BPM**，长 **152 s**。
下行分解伴奏没有变成拨弦任务，也没有新增自动伴奏玩法。
这是用户提供的整份简化编配，不声称包含原唱录音中未给出的所有段落。

用户已明确同意：

1. 保留所有音程，整曲降一八度，将游戏音域扩为 **D3～G5（MIDI 50～79）**；演奏模式保持原样。
   原谱常规 G4 唱名基准下为 D4～G6。第 36 小节双高音点的 1 按原图保留为 G6，输出 G5，没有偷偷折回。
2. 第 **10、18** 小节可见时值各少半拍；将两处“5”由半拍改为一拍，补足四拍。
   这是用户接受的试行修订，不冒充无歧义的原谱内容；原始读法与修订分别保留。2026-10-18 用户下板后认为这两处仍有轻微节奏偏差，但影响不大，当前保留为已知待改进项。

合并 30 个灰色同音延续、保留 13 处休止和三连音，共 **212 次真实起音**。
跨第 5→6、13→14 小节的延音连续，不重复起音。末小节保留完整四拍长音。
没有把前奏循环重复拼成整首，也没有从别处补录未提供的旋律。

## 代码范围

- 原第 3 槽替换为“情歌”，推荐第二音色，菜单/准备/游戏/结果名称同步，舞台标为 MELODY。
  原前奏 CSV/二进制及已发布片段位流保留作历史，不再作为生产槽 3。
- `qing_ge_user_score.py` 用有理数生成全部起音/结束样本，逐小节核对四拍，检查连音相邻与同音。
  生产库现在 959/2048 事件，前四曲 703 事件；前三曲及十分钟诊断的事件数据不变。
- 新 `game_extended` 只用于无需按品的游戏谱。沿用已有分配器的同弦不重叠、临近音换弦代价与密度检查，
  允许四个合成声部接受 D3～G5。原 `physical` 默认仍使用既有 0～8 品候选和 D3～C5。
- P2 控制器的 DDS 暂存/表从 26 扩到 27 个有效位，外部仍为 32 bit 精确相位增量。
  音频链只增加参数，使 P2 的原滑音器用 27 个有效位；其他工程默认仍为 26。
  不扩大滑音器会在 G5 持音时丢掉 bit26，因此新增完整 32 位参考对照。
- 钢琴模态/谐波、音效、采样率、PCM/DDS 分辨率和时钟不变；CST/SDC/接线不变。
  进度步长与目录由同一生成器输出，不再独立写死旧前奏的 128 秒。
- 可见曲名复用现有“情歌”字样，MELODY 使用新消息；字库本体及原标题图块不变。
