# P2 静态长曲／多曲目引擎：第一批核心试写

> 本文是第一批核心试写的历史记录；后续触控、显示和实际音色连接状态见
> [P2 整机集成](P2_STATIC_SONG_INTEGRATION.md)。下文“尚未接入”只描述当时版本。

## 交付范围

2026-10-15 用户明确报告“我已使用P1.fs做过下板确认”，随后要求开始尝试编写 P2 部分代码，
推荐《情歌》第二音色或适合哇音的《Seven Nation Army》，并强调慢速。
用户进一步选择《情歌》的吉他伴奏分解和弦版，本批练习数据按 60 BPM 编排。

**本批交付是核心代码和 RTL／数据验证，P2 尚未完成整机集成。**
原 `.gprj` 新增源文件列表以便查看；`neo_guitar_touch_game_top`、原音频／游戏／显示控制链未替换。
仅运行这个工程仍是 P1 功能，不能在菜单中选择以下原型曲目。本批不产生新的 P2 可下板位流，
也没有为未使用的模块运行整机综合 P&R。后续在同一个原工程中集成和构建。

## 本批实现

- `game_p2_window_controller.v`：每采样最多读 64 条候选事件和 1 条密度保护记录，
  运算量不随全曲 67／300／2048 条事件线性增长；静态曲谱读端口契约是一拍同步读。
  不新增音频 DSP，不把判定和原音源运算合并为同一个调度器。
- 曲谱顺序不可变，窗口以全局事件索引为头指针。消费位只占 64 bit，按全局 ID 低六位索引。
  只有头部已消费／已过期的事件可退休，退休时清槽，后续同槽新事件不会继承旧命中。
  更新中的消费位不直接输出；窗口头和消费快照只在提交时一起发布。
- 曲时、时长、每轨释放时刻改为 32 bit 样本时间，保持 48 kHz。
  首版总时长上限 10 min。命中／漏音／错音／连击为 16 bit 饱和统计，分数为 32 bit 饱和。
- 保留真实拨弦时间戳、最近候选、Perfect／Good／Bad、Wrong 不消费、Miss、四轨和弦、
  试听不计分、退出禁起音和重玩清状态。截止期超时、非法元数据／事件和过密窗口显式报错。
- `game_p2_catalog.v`、`game_p2_score_bank.v`、`game_p2_static_engine.v`：五槽目录、
  单份 2048×96 bit 只读静态数据、音频／显示各自时钟的一拍读接口。
  开始时锁定曲目元信息，播放中更改选择总线不会改变当前曲目。
  **双时钟静态 ROM 的实际 BSRAM 数量和映射尚未综合验证。**

显示端目前只有不可变数据读端口，尚无 P2 帧快照／像素布局适配。
推荐音色编码 0=钢琴、1=第二音色、2=哇音，仅是已锁定的元信息；实际音色切换尚未接线。
未来接入时须沿用退出释放／确认握手，不能在旧声未释放时直接切音色。
P2 fault 也必须接入上层停止和强制释放；目前原型没有直接驱动功放或音频输出。

## 数据与曲目范围

运行时每事件 96 bit：起音32、时长32、MIDI7、轨2、力度2、标志5、分组16。
工具导出的 v2 二进制为 16 字节小端记录，保留字段必须为零，附清单 CRC32。
传输文件头、UART、写曲库和掉电保存不在本批范围。

| 槽 | 数据 | 事件数／时长 | 推荐音色 | 范围 |
|---|---|---|---|---|
| 0 | 茉莉花 | 67／33.75 s | 钢琴 | 与原 P1 样本时刻、DDS、分弦逐项一致，96 BPM 保持 |
| 1 | 原创慢速分解和弦练习 | 256／256 s | 第二音色 | 自编技术练习，每秒一个音，不冒充《情歌》 |
| 2 | Seven Nation Army 短 riff 慢练 | 168／192 s | 哇音 | 七音短主题升八度到 B3～G4，60 BPM 的练习循环；非完整原曲 |
| 3 | 情歌前奏和弦慢练 | 128／128 s | 第二音色 | 四小节前奏和声、重新写的每秒一音分解型、八次练习循环；非完整伴奏 |
| 4 | 十分钟时间边界测试 | 256／600 s | 第二音色 | 仅诊断；普通启动拒绝，须显式 allow_test_slot |

总计 875／2048 条事件，其余记录清零。前三种新练习可用于下一步集成，当前还不能从生产菜单进入。
《情歌》完整主歌／副歌伴奏未转录，没有复制歌词、原版完整曲谱、录音或 PCM。

《情歌》前奏和声依据公开的 [KanPu8 页面](https://kanpu8.com/chords/love-song-fish-leong/) 中
短前奏部分，使用 C 调练习音高；网站另标原调 F#／Capo 6，本批不还原原调。
音符分解型、时长和慢练重复由本批生成器重新编排。
最初检查的 [吉他世界版本](https://www.guitarworld.com.cn/pu/q139290) 完整谱需购买，未绕过限制或下载完整版。
《Seven Nation Army》参考 [National Guitar Academy 教程](https://nationalguitaracademy.com/songs/how-to-play-seven-nation-army-on-guitar/)，
仅将短主题用于慢练，节奏为本批练习编排，不宣称整首或原速逐音复现。

所有新增数据仍使用已有 `game_fingering.py`：保持音高，禁止同弦重叠，临近音优先换弦。
验证 0～8 品可实现性、同轨至少 250 ms、每轨可见窗不超过八块、时间／容量／排序、标志和保留字段。
过密谱报错，不静默丢音；音符数据不是预录音频。

## 已完成验证

基线为 `704fc14`；冻结 P1 控制器和 ROM 保存在 `sim/reference/game_p2/`。
没有修改生产校验器或音频保护来获得 PASS。

| 检查 | 结果 |
|---|---|
| 五项 Python 测试 | 精确迁移、生成物一致、96 bit／二进制往返、保留字段、时间／容量／密度／冲突拒绝、分数拍与自动分弦通过 |
| 2048 事件窗口压力 | 32 次循环槽复用，最多 65 次读、131 个忙时钟／采样；模拟采样周期 256 拍；5,454,876 个时钟 |
| 计分及恢复 | 300 次命中／漏音超过 255 不回卷；退出、重玩、非零曲谱偏移和旧槽清理通过 |
| 长时间边界 | 在测试台推进内部时间越过 2^24 和 600 s 结尾，通过；没有声称按墙钟运行十分钟 |
| 异常场景 | 空槽／非法索引、地址越界、非法音符、65 条近未来事件和截止期违例均显式拒绝；可重启恢复 |
| 冻结 P1 对照 | 完整《茉莉花》试听、拨弦／Wrong／判定／力度／释放、静默 Miss、重玩，合计 12015 个采样边界一致 |
| 数据对照口径 | RTL 对照把双方曲谱时间同样压缩以加速，比较采样边界；Python 另外证明原始 48 kHz 时间、DDS、分弦完全一致 |
| 双时钟 ROM | 2048 次显示读与音频扫描并行，一拍延迟及停读保持通过；启动元信息锁存、五槽／诊断权限通过 |
| 四轨判定 | Perfect／Good／Bad 边界、Wrong 不消费、四轨同时拨弦／力度、释放、Miss 批次、饱和边界和试听分离通过 |
| 语法 | ModelSim RTL 单独按 Verilog-2001 编译，无错误／警告；测试台按 SystemVerilog 编译 |

压力测试的稠密小时间戳是数字边界夹具，不是交付给玩家的音乐。
原音频合成／音效、显示、触控和旧控制器源文件未改动，P1 位流与原验证记录保留；
本批没有重复跑未变化的完整音频回归或原整机网表像素验证。
没有新 Gowin 综合、真实 RAM 映射、完整 P&R／STA、P2 整机网表或 P2 下板结果。
逻辑拍数验证不等于 Fmax 认证，也不据此声称整机资源减少或余量目标已满足。
