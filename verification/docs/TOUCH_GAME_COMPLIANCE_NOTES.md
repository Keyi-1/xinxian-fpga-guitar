# 曲谱引导演奏与赛题实时合成要求

2026-10-14。依据用户提供的 `S:/EdgeDownload/高云 (1).pdf`，不是赛方额外解释或完整合规认证。

## 原文边界

基础要求 1 要求至少两个独立可控的演奏维度。基础要求 3 要求音频根据实时演奏指令逐音、逐样本生成，禁止预录 PCM、预置推流及整段录音触发。拓展要求 4 明确列出脱机曲目指引、在线曲谱下载和演奏键位自定义；现场验证还要求观察不同频率及 RTL 实时合成路径。

由此判断：**“实际拨弦触发音符、当前谱音决定音高”的辅助游戏，本身不等于播放预录 PCM，也没有因省去按品而直接违反录音禁项。** 曲谱是音符事件数据；合成算法及逐样本生成方式才是核对音频核心的重点。

这不表示任何自动曲谱播放都已被确认允许。原文未定义“预置推流”的全部范围，自动试听应与真人实时演奏验收区分；如果将其作为比赛现场功能，需向赛方确认解释。

## 当前路径与证明

- `scores/jasmine_events.bin` 和 `mem/jasmine_game.mem` 保存音高／DDS、时刻、时长和轨道，不保存最终声音样本。
- 游戏模式 `mode=2`：真实压电拨弦事件匹配窗口内谱音，随后送入同一套 FPGA 四声部音源。没有拨弦时谱音只被判 Miss，不会自动 note_on。
- `mode=3` 是显式训练试听：按曲时自动产生音符事件，仍实时运算声音。它没有预录 PCM，但缺少逐音真人触发，不用它替代实时演奏合规展示。
- `piano_voice_core`／实时击弦模型和音效生成逐样本 PCM；PT8211 与标准 I²S 发送同一最终左右声道数据。电脑仅编谱和导入，不推送声音样本。
- 演奏模式保留品位选音及拨弦触发，用于展示至少两个可独立控制的维度。四档力度当前未标定，不能把固定力度编码 2 当作动态力度功能的验收证据。
- 游戏只能作为整机辅助功能，不能仅用“无需按品的游戏”证明所有基础要求；还需完整演奏模式的实时变调、包络、四声部、延迟与音色／音效证据。

## 训练配置与保守比赛配置

顶层 `rtl/top/neo_guitar_touch_game_top.v` 增加两个编译参数，默认均为 1，以保留本次用户需要的试听和 Miss 声音：

| 参数 | 训练默认 1 | 保守比赛配置 0 |
| --- | --- | --- |
| `ALLOW_AUTOPLAY_PREVIEW` | 试听按谱自动演奏 | UI 不接受试听，音频路由也拒绝自动演奏模式 |
| `ENABLE_MISS_CUE` | Miss 混入短促提示声 | 不实例化提示音合成／混音模块，仅保留屏幕和统计反馈 |

比赛配置可将这两个顶层参数的默认值改为 0，重新仿真、综合和布局布线；参数改变后的位流须另作资源和时序验收，不能沿用训练位流哈希或报告。当前交付若未特别注明，为训练配置。

Miss 提示是独立的实时三角波加短包络，约 30 ms／750 Hz，不读取录音，不占用吉他声部，不改变原音色。它由漏音判定计时触发，严格解释“所有输出均根据实时演奏指令”时仍有讨论空间，因此提供关闭参数。关闭它无需删除显示上的 Miss、得分或真人拨弦声音。

建议比赛现场先展示演奏模式：随意改品、松品续音、改变音色／音效、四音齐拨；展示标准 I²S 波形及合成 RTL。游戏展示“计时只移动提示、实际拨弦才发出谱音”。训练试听和 UI 提示声单独说明，不把它们作为真人演奏性能的证明。
