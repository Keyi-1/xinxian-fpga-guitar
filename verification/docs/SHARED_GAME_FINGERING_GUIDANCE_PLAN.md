# 矩阵指板与四轨提示的共享分弦方案

日期：2026-10-15。状态：**矩阵版仍为方案；用户已选择先实现原全宽舞台四轨版，暂不加入 4×9 矩阵和后续折线动效。**

最新实施补充：`tools/game_fingering.py` 已接入《茉莉花》生成器，四轨的共用分弦规则已实现；包含束搜索死路后的完整可行性复核及随机小谱枚举对照。矩阵画面／品位判定仍未加入 FPGA。当前具体实现、验证与实物边界见 [FULL_WIDTH_GAME_STAGE.md](FULL_WIDTH_GAME_STAGE.md)，下文其余矩阵部分保留为后续设计。

用户已确认：矩阵版需要按对品位并拨对应弦；原四轨版继续无需按品。两种界面均需遵循同弦冲突约束和相邻音优先换弦的规则。

## 1. 界面和操作

- 矩阵为 4 行 × 9 列：从上到下为第 1～4 弦，颜色为蓝、绿、橙、红；从左到右为空弦、1～8 品。
- 只亮当前提示组需要演奏的格子，每行最多一格。和弦可同时亮多行；空弦亮第一列，并要求该弦没有按品。
- 不把后续音符同时亮在矩阵里，避免同一行出现两个待按位置。矩阵触摸不代替真实按品／拨弦。
- 用底部准备进度提示到拍拨弦；四轨版继续由色块中心到达既有 x=96 判定线提示时刻。
- 预览可在矩阵／四轨之间切换，也可查看《茉莉花》开头、独立三音和弦、四根空弦示例。三音和弦不是对现有《茉莉花》资产新增的伴奏。
- 真实实现时，两种界面读取同一曲目、同一时间轴和同一分弦结果；切换外观不能改变谱面时刻、音高或时长。

当前硬件调弦和品位范围来自 `fret_note_event.v`、`note_phase_table.v` 及已验证的矩阵链路：

| 行／弦 | 空弦 | MIDI | 0～8 品的可用 MIDI 范围 |
| --- | --- | --- | --- |
| 1／蓝 | E4 | 64 | 64～72 |
| 2／绿 | B3 | 59 | 59～67 |
| 3／橙 | G3 | 55 | 55～63 |
| 4／红 | D3 | 50 | 50～58 |

对应物理品位为 `fret = midi - open_midi[string]`，只能取 0～8。此表不是旧四轨教学谱的人工音域分组，不能沿用旧 `lane` 字段而直接猜品位。

### 动效预览补充

2026-10-15 按用户要求增加独立动效预览：切换目标后约 220 ms 快速亮起；演示按钮展示准备进度、模拟命中、局部光环扩散和约一秒内的渐暗。矩阵的光环限制在目标格附近，未选中格保持暗色；四轨版在判定线增加短促光环及分段弦波。

动效不在载入时或切换界面时自动播放；用户操作后单次演示，支持停止并尊重减少动态效果的设置。预览里的准备时间用于看清效果，不改变真实曲谱拍点。正式实现时由实际目标切换／真实命中触发，动画不得产生虚假命中、自动发声、改变判定窗或延迟下一音提示。密集音符时优先保证目标清晰，压缩／合并同一弦的视觉尾迹。

板上实现候选为少量分层矩形、有限帧强度表、逐弦动画年龄计数和短分段波形；不据此承诺零新增资源。需要审核效果后结合现有高占用工程完整实现验证，再决定保留哪些效果。此动效仍只在预览中，未增加任何显示 RTL。

## 2. 共用分弦的硬约束

1. 音高、起始时刻、谱面时长保持不变，不能为了换弦静默移调、删音或挪动拍点。
2. 同时起音的音符必须使用不同弦，一根弦不能在同一时刻承担两个独立音符。
3. 对谱面明确要求重叠保持的音符，区间 `[onset, onset + duration)` 不能占用同一弦；恰好前一音结束时允许重用该弦。
4. 约束中的保持区间指谱面音符持续时间，不包含公共混响、合唱和自然尾迹。不能为了等待混响完全消失而永久锁住弦；不能为了排谱而简化音色或音效。
5. 最多使用现有四个固定弦声部。超过四个同时音，或其他无法找到合法指法的组合，应报告具体冲突位置。
6. D3 与 E3 都只能由第 4 弦产生；二者同时或需要重叠保持时，当前调弦与品位范围不能满足。重配八度、改编声部或调整节奏须另行确认。

## 3. 软目标：相邻音换弦与可演奏性

在所有满足硬约束的方案中，优先减少短时间内重用同一根弦，再综合考虑高品位、连续手位移动和和弦品位跨度。相邻音跨弦不是绝对条件；候选音域只有一根弦时，允许顺序重用。

不采用 `MIDI % 4` 或简单轮换弦号。这些方法会产生物理上不存在的品位，并可能让复音发生冲突。也不逐音贪心选最低品，避免先占用某根弦后使同组剩余音无处可放。

推荐在电脑端曲谱生成／导入阶段，以同起音组为单位枚举不冲突的候选指法，并使用动态规划或有界束搜索比较前后组。跨组状态保留每弦的占用结束时刻、上次起音时刻与品位。导入后 FPGA 保存已确定的结果，独立演奏时不需要电脑继续连接，也不在音频采样周期执行搜索。

束搜索是有界近似算法，不能把“束宽内未找到”当作数学上一定无解。生产导入器应在该情况增加搜索预算或进行完整可行性复核，再区分确实无解与搜索受限；发现无解不能任意改音高。

当前交互预览使用 128 状态的局部束搜索演示分弦规则，未把该算法添加到 FPGA 工程或正式曲谱生成器。

## 4. 两种模式的判定与声音

| 项目 | 矩阵指板练习 | 原四轨拨弦游戏 |
| --- | --- | --- |
| 起音条件 | 实际拨弦 | 实际拨弦 |
| 命中条件 | 时间窗、弦号、实际稳定品位均正确 | 时间窗和弦号正确，忽略品位 |
| 空弦 | 实际稳定品位必须为 0 | 不检查品位 |
| 正确起音 | 实际指法与目标音高一致 | 使用谱面目标音高 |
| 同时音与近邻音 | 共用分弦结果 | 共用分弦结果 |

矩阵判定应在音频时钟域的拨弦事件发生时锁存同域稳定品位，避免页面／显示域 CDC 延迟影响判定。错品或错弦不能被自动纠正为正确音；建议用该弦拨弦瞬间的实际指法音高发声。游戏音符持续时间仍由事件管理，音源逐样本实时合成。

原四轨错误拨弦、命中／漏音和试听行为、得分窗口，以及训练／保守比赛参数继续沿用既有规则，除共享分弦外不在此次外观改造中擅自更改。矩阵的品位判定只作用于新练习模式；自由演奏的按品滑音、松品续音、三音色、音效及两路音频输出保持原有行为。

## 5. 提示时序与复音

- 提示推进依照谱面时钟，不等待用户拨完才推进，避免改变节奏。
- 将同起音音符组成一个目标组；矩阵每行最多一个目标，本组某音命中后可熄灭对应格，其他音继续等待各自判定。
- 允许人手多弦拨动存在时间差，沿用逐音判定窗口，不要求多弦拨弦脉冲出现在同一 FPGA 时钟。
- 矩阵的提示焦点与判定窗口分别管理。建议根据相邻起音时刻中点确定提示组切换，并对提前量设上限；后续组出现时不在同一行叠加旧组格子，旧事件仍按原时间窗完成判定。
- 对太密集、来不及预读的矩阵谱，应提示难度／准备时间限制；不能通过拖慢曲谱或复制音符隐藏问题。
- 发生重拨、退出、重玩和换曲时清理事件代号，旧 `note_off` 不能关掉新起音；不改变原自然衰减与公共效果处理。

## 6. 实施位置与资源策略

审核通过后实施共享曲谱分配，再接两种显示和判定。现有谱面需从音高、时刻、时长重新生成 `string/fret`，不只是美化旧 lane 标签。

每个事件增加明确的弦号与 4 位品位元数据（0～8），并区分教学玩法。ROM／CSV／传输格式显式版本化；不能在未协商格式时挪用 flags 导致未来 UART 导入不兼容。

四轨版继续显示分配后的弦，不因无需按品而另做一套随机分弦。矩阵版用当前 4 行的目标有效位和品位寄存器，最多四个目标；像素阶段先解码所在行列，再判断是否命中目标，避免展开 36 套完整坐标比较或加入帧缓冲。坐标解码优先边界比较／计数，避免新增通用除法器。

当前 CLS 约 99.31%，任何实际实现仍需完整综合、P&R、STA 和网表检查，不能凭预览推断资源够用。优先复用快照、字模、计分和已有音源，不新增音源、DSP 运算或削减原三音色。

## 7. 审核后需要的验证

- 同音可换弦、不可换弦的最低音、八品边界与超音域。
- 二／三／四音和弦的一对一分弦；重复同音、跨组保持重叠、恰好结束时重用和真正无解组合。
- 同一曲谱的两种界面读到相同事件，原四轨忽略品位，矩阵错误品位不得取得命中。
- 空弦与多品同时触碰按现有最高品规则判定，稳定品位与拨弦同域取样。
- 矩阵目标组切换、快速八分／十六分音、Miss、重拨、重玩、换曲和退出；无旧事件漏到新局。
- 显示完整动态场景的 RTL 与综合后网表对照；音频关闭新模式时与已验收基线逐样本一致。
- 实物确认四行四弦、空弦及 1～8 品方向，三／四弦同时拨动不误判；保持原音色和音效听感。

本轮仅完成交互预览及上述设计。现有 `rtl/`、曲谱资产、约束、工程和位流均未修改。
