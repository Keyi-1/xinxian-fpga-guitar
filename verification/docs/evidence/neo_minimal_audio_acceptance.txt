2. Repository source of truth

Board top:
rtl/top/neo_minimal_audio_top.v

Physical constraints:
constraints/neo_minimal_audio.cst

Timing constraints:
constraints/neo_minimal_audio.sdc

The board top asserts reset asynchronously and releases it through a two-stage
synchronizer in the 12.288 MHz audio domain. It also converts the core's
active-high PA request into the NEO Dock's active-low pa_en_n and forces the
amplifier off while the audio domain is in reset.

The SDC contains exactly three single-line commands: one clock constraint for
50 MHz, one for 12.288 MHz, and one asynchronous clock-group declaration. It
does not use backslash line continuation.

The Gowin project contains flat copied sources with local include/readmemh
paths. Those project-only path changes were intentionally not copied back into
the repository's normal rtl/mem directory structure.

4. Hardware acceptance

Verified physical chain:
12.288 MHz MS5351M CLK2 -> USR_CLK_IN/V13 -> E4 phase increment ->
voice_audio_core -> PCM24-to-PCM16 -> pt8211_tx -> NEO Dock PT8211 ->
3.5 mm left and right outputs.

Observed results:
- CLK2 independently returns to 12.288 MHz after a complete power cycle;
- no computer, external MCU, BL616 runtime configuration, or soft CPU is
  required during operation;
- measured output pitch is E4, approximately 329.63 Hz, with small error;
- both left and right 3.5 mm channels produce output;
- continuous playback is stable, with no obvious periodic pop or dropout;
- holding KEY0/S4/AA13 mutes the output;
- releasing KEY0 retriggers E4 automatically.

SW7/RECONFIG/N12 is a dedicated FPGA reconfiguration input. Pressing it after
an SRAM download clears the current configuration and requires another
Program/Configure operation. This is normal and is not an RTL reset failure.
