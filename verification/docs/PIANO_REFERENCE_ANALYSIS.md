# 库乐队古典大钢琴参考：分析与离线重合成

日期：2026-10-04。用户提供三个单音各弹两次、C/E/G 合音弹两次的四个 WAV；
音色为“古典大钢琴”，压缩、高音、低音、回声均为 0，混响开启，人工尽量保持相近力度。
用户已明确希望 FPGA 音色向这份古典大钢琴靠近。

后续进展：用户认可本页离线样音后，已在独立分支实现钢琴模态与击弦起音，
并接入物理主工程，见 [FPGA 钢琴试验说明](PIANO_FPGA_TRIAL.md)。以下是此前录音分析阶段的记录。

本次完成原始文件分析、可复现参数提取、频谱图和离线试听样音。
**这些样音不是 FPGA 输出，该分析阶段的主工程仍使用原来的正弦音源；该阶段没有修改音符 ROM、
主 RTL、约束或位流。** 之前全链路验证成功的输入控制、接线和工程均保留。

## 主要结论

1. 当前默认主工程的单声部只有一个正弦分量。参考钢琴包含多组强弱不同、
   随时间变化的分音，以及起音瞬态和立体声空间信息。
   前一轮降低近邻声部音量，只针对叠加包络起伏，不会把正弦波变成钢琴。
   正弦波本身也能组成和弦，不能据此断言所有“不融合”都来自缺少泛音；
   但它与这份目标音色的差距有直接的频谱证据。
2. 参考合音保留了三个单音的主要频率。没有发现它通过大幅改变三个基音来形成和弦。
   目标应是声部的音色、起音、衰减和空间感，而不是随意调整音符表以“消除拍频”。
3. 参考中也有接近的分音：C 的第三分音约 1576.4 Hz，G 的第二分音约 1573.3 Hz，
   相差约 3.2 Hz。这说明目标钢琴本身允许产生慢起伏；消灭所有拍频不是合适的验收条件。
4. 文件标为 C4/E4/G4，但主要周期对应约 523.4/659.9/785.1 Hz。
   以 A4=440 Hz 的常用科学音高编号，更接近 C5/E5/G5。
   所有试听对照按实测频率生成，不因文件名将音高降低一个八度。

## 音高与分音

分析起音后 80～700 ms 的 Hann 窗；分别计算左右声道频谱，再平均功率，
避免将反相立体声信息先混成单声道而丢失分音。
窗长 620 ms 对应约 1.6 Hz 的基本频率分辨尺度；262144 点零填充使显示网格约 0.168 Hz，
峰值插值有助于重复比较，但零填充不等于提高真实的分辨能力。
表中小数用于描述谱峰位置，不代表对应精度的物理调音保证。

| 文件 | 单音主要频率 | 合音第一下中对应峰 | 文件名常见编号的频率 | 后者相对主要峰的电平 |
|---|---:|---:|---:|---:|
| C4 | 523.4 Hz | 523.3 Hz | 261.6 Hz | -40.6 dB |
| E4 | 659.9 Hz | 659.8 Hz | 329.6 Hz | -39.5 dB |
| G4 | 785.1 Hz | 785.1 Hz | 392.0 Hz | -38.5 dB |

第一和第二次单音的主要频率估计差均小于 0.01 Hz；前六分音的相对电平最大差约 0.10 dB。
这是本文件和本分析窗的重复一致性，不是对录音设备误差或所有力度层的测量。

Apple 的 [Logic Pro 八度编号说明](https://support.apple.com/en-mide/guide/logicpro/lgcp9793a910/mac)
表明八度标签可能采用不同约定。这不能直接证明用户的 GarageBand 使用了哪种编号；
这里只以实际 Hz 为依据，也可能是录制时选中的八度不同。
当前四弦音符表按 D3/G3/B3/E4 空弦与 0～8 品生成，覆盖约 146.8～523.3 Hz，
参考中的 E、G 实测频率已经高于这个范围。**本次不会把整个乐器移调来对齐录音。**

以下电平以各自第一分音为 0 dB，是起音后分析窗内的相对谱峰，
不是击弦瞬间的初始幅度 ROM：

| 分音序号 | C | E | G |
|---|---:|---:|---:|
| 1 | 0.0 dB | 0.0 dB | 0.0 dB |
| 2 | -12.0 dB | -13.3 dB | -5.9 dB |
| 3 | -21.1 dB | -26.8 dB | -15.9 dB |
| 4 | -29.0 dB | -19.4 dB | -26.9 dB |
| 5 | -29.1 dB | -30.5 dB | -34.3 dB |
| 6 | -28.0 dB | -32.6 dB | -39.1 dB |

G 的第二分音更强，E 的第四分音突出；三音没有共享一个逐级减半的幅度比例。
仓库可选谐波核的 classic 表约为 0/-6/-12/-18/... dB，且当前物理主工程默认未启用它。
仅启用该表不能视作复刻这份钢琴。

分音频率略高于基音整数倍。用
`f_n = n*f_1*sqrt((1+B*n*n)/(1+B))`
拟合前六个中可靠的谱峰，得到 B 约为 C:0.00103、E:0.00124、G:0.00151，
拟合均方根频率残差约 1.1/0.6/0.9 Hz。这里 B 的定义以实际第一分音为基准；
不能直接与使用“理想无刚度弦基频”的 B 公式互换。
该特征与钢琴弦谱线偏离整数倍的情况一致，但无法由此识别库乐队内部的音源实现。
相关原始研究：[Anderson & Strong, 2005](https://pubmed.ncbi.nlm.nih.gov/15957792/)。

## 起音、衰减与合音

录音呈现较强的短起音、迅速变弱的主体和更长的尾部；不同分音的包络也不相同。
用 ±24 Hz 复解调低通估计每个分音的立体声能量包络。
它包含邻近模式、琴体/空间效应和混响，低通本身会将起音展宽，不能据此给出准确的击弦 Attack 时间。
C 的第二分音包络有明显非单调变化，其他分音也有起伏，单一指数衰减只是粗略近似。

分析数据中的双指数拟合仅拟合观察到的 40～700 ms 包络；
有些参数触及拟合边界，慢衰减项不一定可识别。
用户何时松键未知，也没有干声或混响脉冲响应，**不能将这些数值直接解释成弦衰减时间、
钢琴 Release 或房间 T60，更不能直接作为主工程默认参数。**

对合音第一下，在相同分析窗与 350～5000 Hz 范围，做非负的单音功率谱组合。
允许三个自由权重，以容纳力度和导出归一化差异。得到权重约 0.324/0.501/0.354，
功率谱 L2 相对残差约 0.074。主要峰可以较好解释，但这个指标偏重强峰，
**不代表 92.6% 的听感相似度，也不能证明库乐队只有线性相加、没有共鸣或其它处理。**
因为相位、力度和立体声样本可能不同，本次没有通过波形相减来断言动态压缩或非线性。

参考有复杂的左右声道信息；当前主工程则将各声部动态分配到完全分离的两侧。
对新的钢琴方向，可以尝试更窄、固定的键位声像和同一空间的混响，
而不是继续以强制左右分离、按相邻音衰减作为主要音色塑造方式。
这是待试听验证的工程选择，不是这些文件已经证明的唯一原因。

这些音频由振荡器和测得的慢变化幅度生成，不是回放原始 PCM 采样。
它们没有完整重建击弦瞬态、多个弦模式、相位和琴体共鸣，且使用湿声包络、额外添加了一个小型模拟房间；
不能称为已分离的干钢琴或库乐队同款音源。
目的在于给后续音色实现一个可试听的方向，不保证加法合成已能达到目标音色。
现代钢琴建模研究也分别处理分音、瞬态和噪声，并报告起音部分仍有明显感知差异：
[Simionato & Fasciani, 2025](https://www.frontiersin.org/journals/signal-processing/articles/10.3389/frsip.2024.1494864/full)。

## 向 FPGA 实现转换的具体方向

本次不改动已工作的输入链；后续音频核可采用以下实现顺序：

1. 增加独立的钢琴音色选项，保持当前音符 ROM 的基音，先使用约 6～8 个可靠分音，
   按音区选择幅度与衰减参数。三份相近高音区参考只能作为初始音色，不足以标定完整低音区和四级力度。
2. 每个分音有独立相位累加器，频率比乘以 phase increment 后累加。
   **不能把已经绕回的基音 phase accumulator 乘上非整数频率比**，否则在每次基音相位绕回时会出现不连续。
   当前 `harmonic_voice_core` 使用基音相位乘整数序号，需要另行实现模态相位状态。
3. 使用足够小数位的分音包络，避免把很慢的衰减直接以 16 位幅度逐采样截断；
   分离起音、主体和松品阻尼。混响留在公共空间处理，而不直接固化到每个分音的湿包络中。
4. 另行建模短击弦瞬态。可比较小段 Attack ROM 与简单瞬态合成的效果，
   而不假定再增加几组稳定正弦就能自动得到钢琴。
5. 钢琴模式优先验证固定混音余量、窄声像与公共混响，去掉按近邻音龄改变和弦配比的依赖；
   保留旧音色作为对照。先检查数值削波，再做耳机/双扬声器试听。
6. 用同音高、同力度、同总电平导出新旧 RTL 音频；覆盖大三和弦、近邻不协和音、错时拨弦、
   四音、重触发、滑音、松品。通过音频检查、仿真和固定引脚时序验证后，才生成用于板上验证的版本。

若要更接近原钢琴，后续最有价值的补充是关闭混响的同音区单音，
以及覆盖实际 D3～C5 范围的几个代表音、注明保持与松键时间。
现有文件足够完成本次分析和方向样音，不需要重录才有这些结论。
