# 许可正文

- [Apache-2.0.txt](Apache-2.0.txt)：Apache 官方协议正文，与根目录 LICENSE 相同。
- [GPL-3.0-only.txt](GPL-3.0-only.txt)：GNU GPLv3 正文；Windows 客户端选择 GPL-3.0-only。
- `third_party/`：从已验收 Windows 包及相应上游源码包原样保留的许可文本。
- [third_party/source_downloads.json](third_party/source_downloads.json)：准确版本的上游源码地址和散列。
