FPGA 吉他 · 曲谱上传 1.0

先把 ZIP 完整解压到一个文件夹，再双击 FPGA_Guitar_Uploader.exe。
无需安装 Python。不要单独移动 EXE；_internal 文件夹是运行所需的库。

1. 开发板保持供电，用 DEBUG-USB2 连接电脑，在琴上回到主页或选曲页。
   软件里点击“刷新”，选择对应 COM 口，然后点击“检查设备”。
   COM 号不确定时，可在 Windows 设备管理器的“端口”里看，或拔插对照。

2. 点击“打开示例曲谱”，先选“入门示例.csv”，或“情歌_60BPM.xgscore”。
   等待校验通过，核对事件数、时长和音色。
   需要自己的曲谱时，可参考“示例曲谱/CSV格式说明.txt”。

3. 推荐先选第 2 槽，点击“确认并上传”，核对替换信息后确认。
   等待明确显示“上传成功”，再在琴上选择 USER 2，先试听再演奏。

串口打不开：关闭串口助手和其他占用同一 COM 的程序。
没有响应：检查是否选对串口、DEBUG-USB2 连接和当前 FPGA 位流。
BUSY：退出演奏、试听或游戏，回到主页/选曲页。
NO_SPACE：五槽共享空间不足；替换时旧曲与新曲要暂时同时存在。
提交结果未知：先检查设备，在琴上试听确认，再点“处理上次提交”。

曲谱保存在 RAM，断电、复位或重新配置 FPGA 后会丢失。
本软件支持 Windows 10/11 x64；没有在实物 COM 口执行自动上传测试。
更详细说明见“使用说明.md”和软件右上角“使用说明”。
