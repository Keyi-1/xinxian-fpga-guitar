# 2026-11-02 最终源码与发布基线

本版本合并已完成验证的 FPGA、安卓 0.3.0 和 Windows 1.2.0 源码。音频仍由 FPGA 逐音逐样本生成，保持四独立声部、总计 32 个物理模型状态、48 kHz 音频及 100 MHz KS 运算时钟。

## 已完成的功能

- 保留用户确认的 KS 五度推荐版音色及其根音主体；KS 等价流水优化只改善时序，不改变输出 PCM。
- 显示与触控统一旋转 180°；MPU6050 分类兼容正负琴颈方向，传感器安装方向保持原设置。
- 内置曲谱依次为 1 茉莉花、2 Seven Nation Army、3 情歌；4/5 同样显示“待导入”。
- Windows 经 DEBUG-USB2、115200/8N1 传谱；安卓经 JDY-23、9600/8N1 传谱。两个 UART 与帧接收器并行、一个协议核按完整帧 TDM，独立保存两端会话、重试及错误状态。一次上传独占共享导入器，另一端可查询，写入返回 BUSY。
- 安卓新版界面、图标、可关闭音符动画及系统栏安全区；Windows 同步槽位与音色名称。两端内置生日快乐歌、我不难过和 City of Stars，支持原有文件导入。

## 构建入口与证据

FPGA 正式工程为 `gowin/neo_guitar_touch_game/neo_guitar_touch_game.gprj`，器件与原时钟约束保持不变。可在 Gowin V1.9.12.03 中打开该工程，执行综合与布局布线。最终实际资源为 Logic 50937/59904、FF 23686/60780、CLS 28807/29952、BSRAM 118/118、DSP 106.5/118；系统／音频／KS Fmax 为 52.375／18.044／109.368 MHz，setup、hold、latch、未布通均为 0。

最终认证为 `build/dual_score_transport/verification.json`，其中源码哈希与实际综合输入绑定；`source_package_manifest.json` 列出纯源码包的 140 个实际工程依赖。源码包不含 README、位流、报告或仿真产物。`rtl_10`、`query_tdm_02`、`full_gate_03`、`uart_gate_04` 为最终通过记录，正式报告与位流另存于固定发布 ZIP。

真实 9600/115200 双接口波特率由生产 RTL 验证。完整实际网表串口场景使用已登记的 UART 计时高位加速；完整音频／菜单场景对照实际网表与 RTL。门级仿真未使用 SDF，时序由实际 P&R 的 STA 独立验证。细节见 `DUAL_SCORE_TRANSPORT.md`。

安卓构建入口为 `python tools/build_android_jdy23.py`，Windows 为 `python tools/build_windows_score_uploader.py`；依赖安装与使用见各自 README。软件验证涵盖 Android API35 普通屏幕、小屏、大字体、横屏、挖孔五场景共 195 项，以及 Windows 34 项回归、冻结 EXE 与分发源码校验。软件原发布字节保持。Android 签名密钥保留在本地忽略目录，不上传到仓库。

历史 `tools/build_*`／`check_*_result.py` 脚本含构建时 HEAD、源码及回退版本保护，用于审计对应冻结批次；提交变化后不放宽旧证书，也不以旧证书认证新构建。新构建应以实际产物重新验收。
