## 杜邦线接法

用户实物为GY-521/MPU-6050，尚未固定琴身。使用独立GPIO总线，不与原生J6触控共享，不改原ADC/矩阵/I2S接线。

| MPU模块信号 | NEO Dock 31005 | FPGA/用途 |
| --- | --- | --- |
| VCC | J8-1（3V3） | 模块电源，先核对实物供电 |
| GND | J8-3 | 共地 |
| SCL | J8-11 | Y21，Bank8，开漏GPIO |
| SDA | J8-12 | Y22，Bank8，开漏GPIO |
| AD0（用户写ADO） | 接模块GND | 地址0x68 |
| XDA、XCL、INT | 留空 | 本版轮询数据就绪，不使用辅助总线/中断脚 |

J8-2同为3V3、J8-4同为GND，但上表只指定一套接点。按板上排针编号连接，不按图片左右方向猜位置；J8-5～8继续留给ADC，J13矩阵、J9 I2S、J6触控和LCD跳帽保持。SCL/SDA只驱动0或高阻。

核对依据为官方31005原理图第19页（J8电源及PMOD1_IO0/1），两版60K核心板Bank8/Y21/Y22和BTB连接，以及官方60K约束；原PDF/哈希在 `build/p3_import/board_evidence/`，本批页图在 `build/p4_posture/board_evidence/`。链接：[31005原理图](https://dl.sipeed.com/fileList/TANG/Mega_138K_60K/02_Schematic/DOCK/Tang_Mega_NEO_Dock-138K_31005_Schematics.pdf)。

用户所说3V3尚不是供电实测记录。断电接线；先只接模块VCC/GND，确认稳压后芯片供电和SDA/SCL上拉电平兼容，再接信号。不同GY-521稳压器/上拉可能不同；不能为了修复不通信直接改接5V。原保护方案中的供电/上拉检查继续适用。

## 首版交互和安装

上电默认MANUAL、钢琴，未校准和传感器离线不自动切换。主页底部左侧`CALIBRATE`、中间`AUTO OFF/ON`、右侧健康/姿态；演奏页右下角显示`MANUAL/AUTO/WAIT TAIL`等状态。原游戏页面和触控职责保持。

1. 默认轴向为模块+X指向琴颈、+Z指向琴面正面；+Y完成右手坐标系。先临时固定或用手保持与琴身一致的方向，避免杜邦线拉动。需要换轴/反号时修改显式参数并重新验证，不靠零偏校准掩盖轴向错误。
2. 将琴面+Z朝上水平静置，点击`CALIBRATE`。收集256个连续静止有效包，约2.56秒；移动、跳变、失联或断包会重新计数。陀螺仪均值去零偏，加速度Z保留8192LSB的重力。校准后另等至少1秒健康数据。
3. 出现FLAT/GUITAR/UPRIGHT/READY等状态后，点击`AUTO ON`，再进入演奏模式。
4. 新确认的平放姿态选择钢琴；斜抱选择明亮弦音。原音色键继续按钢琴→明亮→哇音循环，处于同一姿态时手动选择保持。
5. 自动目标等待全部声部自然结束、无待处理起音，且至少两个采样边界确认流水线排空。持续延音可以长期`WAIT TAIL`；不缩包络、不强制截音。手动按键取消待命目标，模式退出使用原停止流程。
6. 竖抱仅报告UPRIGHT，琵琶未实现，因此不改变为假冒的第四音色。游戏默认不受AUTO影响，仍使用曲目推荐和原手动键；菜单只监测。
7. 失联保留当前音色和声音，手动键继续有效。恢复后重新等待健康数据，同一姿态不重发默认音色。复位/重新配置需重新校准和启用AUTO。

这是方案中的“等待音源空闲”的验证版。逐声部起音音色锁存、混合音色尾声隔离、琵琶、蓝牙和断电保存均不在本批。

## 数字验证进度

独立驱动覆盖一字节指针、复位/ID、10项配置写入和逐项回读、14字节大端有符号包、未就绪、NAK、坏ID/配置、过期、时钟卡死和恢复。共享I2C主机的默认两字节路径保留并回归GT911。
