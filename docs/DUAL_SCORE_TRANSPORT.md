# Windows USB 与手机蓝牙传谱

适配 Windows 便携版 **1.2.0** 和安卓 JDY-23 APK **0.3.0**。两个软件的 XG3 协议、音色编号和曲谱资源保持原样。本次修复位于 FPGA：此前 JDY-23 版本把唯一导谱 UART 从 DEBUG-USB2 迁到了 J8，Windows 原 USB 路径因而不通；新版本同时接出两路独立 UART。

| 入口 | 连接方式 | 波特率 | FPGA TX / RX |
|---|---|---|---|
| Windows | 开发板 DEBUG-USB2 接电脑，选择对应 UART COM 口 | 115200 / 8N1 | U15 / V14 |
| 安卓 | 手机 BLE 连接 JDY-23，模块维持原 J8-9/10 接线 | 9600 / 8N1 | AB21 / AB22 |

Windows 继续使用现有 DEBUG-USB2 数据线和板载 UART 桥，无需外接 USB–TTL 转换器或刷写 BL616。手机继续使用现有 JDY-23 接线及 FFE0/FFE1 服务。两个入口可同时连接；上传一首曲谱时由发起 BEGIN 的入口独占写入，另一路上传返回 BUSY，等待当前上传结束后重试。其他入口可以查询曲库。

## 使用

1. 使用本次 `neo_guitar_touch_game_ks_fifth_v2_lcd180_slots123_dual_uart.fs`。此前仅带 J8 UART 的 `.fs` 无法通过修改 Windows 软件恢复 USB 引脚路径。
2. 在琴上回到主页或选曲页，保持供电。Windows 刷新 COM 后检查设备；手机连接 JDY-23 后等待握手和五槽查询完成。
3. 选择曲谱、音色、目标槽位，确认上传。等待 FPGA 明确确认提交，在琴上选择对应 USER 槽试听。不要让两端同时替换同一槽。
4. 导入数据仅保存在 FPGA RAM 中，断电、复位或重新配置后恢复默认目录。

默认第 1/2/3 槽分别是茉莉花、Seven Nation Army、情歌；第 4/5 槽均显示“待导入”。音色 0/1/2 分别是钢琴、明亮弦音、哇音。

两个客户端附带的生日快乐歌、我不难过、City of Stars，事件数据逐字节一致，分别为 25/564/491 条，共 1080 条。导入空间为五槽共享 1345 条；原有导入曲在替换提交前仍占空间，所以后续替换仍可能返回 NO_SPACE。

## 实现与验证

两路 UART 和完整帧接收器并行工作。每路暂存一个完整请求，仅将 magic 后的 28 字节存入寄存器；半帧超时、UART 坏停止位和队列占用均有检查。一个协议计算内核逐帧轮询两路，使用一个 234 位非活动上下文与活动内核交换，分别保存两端的会话、序号、重试缓存及错误计数。两个端口即使使用相同会话号和相同序号，也不会串用响应。

发送和接收的 CRC 组合网络复用，CRC 状态分开保存。接收器在请求完整后回放给协议核；UART 发送器独立保存正在发送的字节，端口切换不破坏上一端的最后一个响应字节。上传仍由 BEGIN 的入口独占原导入器，非所有者的写入命令返回 BUSY；目录查询可以在两端按帧交替完成。原主机超时和停等协议保持。所有队列和上下文均使用寄存器，不依赖本器件不可用的 SSRAM。

验证包含冻结旧解析器与直接回放解析器的 1025 帧周期/CRC/字节/命令对照；真实 9600/115200 双端导入；以及相同会话号下 32 组不同槽查询、相同请求的不同缓存 STATUS、CRC 与坏停止位错误计数隔离。共享原曲谱导入器、BSRAM、读回 CRC 和跨时钟域原子提交。

音色与 KS 内核、四声部/32 模型状态、50/12.288/100 MHz 时钟、48 kHz 音频、显示/触控 180°、MPU6050 姿态和曲谱内容均保持。新增接口不增加曲库 BSRAM 或 DSP。

构建及验证记录位于 `build/dual_score_transport/`。原工程仍是 `gowin/neo_guitar_touch_game/neo_guitar_touch_game.gprj`，可用位流位于其 `impl/pnr/`。以该目录最终 `verification.json` 和独立发布包记录的哈希、实际网表测试及 STA 结果为准。仿真不使用 SDF，时序另外检查实际 P&R 报告。

真实 9600/115200 波特率在生产 RTL 中验证；完整实际网表的串口场景采用显式计时加速，仅对经审计的 42 个 UART 倒计时高位 Q 置零（BLE 5208→24、USB 434→50 个系统时钟），参考 RTL 做同一处理。数据、FIFO、协议、CRC、导入器、BSRAM 和跨域提交均正常运行，另将触控控制器的就绪注册输出作为已登记输入刺激。该网表场景不冒称原波特率实测，未完成的原速网表运行保留为不完整记录。
