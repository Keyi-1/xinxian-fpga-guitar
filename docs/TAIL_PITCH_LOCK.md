## 演奏行为

每弦独立保留发声目标音高和下一次拨弦的准备音高：

| 动作 | 发声与准备状态 |
| --- | --- |
| 按第一品，真实拨弦 | 第一品起音，解除该弦尾音锁定 |
| 松开第一品 | 锁住本次声音的目标音高，原包络自然衰减 |
| 再按第三品，但不拨弦 | 准备第三品；第一品尾声继续，不重新起音 |
| 再次真实拨弦 | 按当前稳定品位起音并解除锁定；无按品则弹空弦 |
| 保持接触，直接换品或重叠换品 | 尚未锁定的本次声音继续使用原滑音 |
| 同品三次合格松按 | 继续触发原颤音，基准音高仍来自本次声音 |

取消颤音的条件仍包括松品、换品、重拨、声部自然结束、退出演奏模式和复位。
新快速松品观察也会及时取消该弦颤音，但不计入颤音松按次数、不改变原
60～200 ms 松开要求、600 ms 窗口、6 Hz 和约 ±20 cents 深度。
松品不发出 `note_off`，按品不产生 `note_on`，没有用硬截断或补拨弦掩盖问题。
四根弦的锁定、拨弦及颤音互不串扰。

`piano_voice_core.v`、包络、模态表、音效和其余音源源码与已推送版本逐字节相同。
已经完成的钢琴自然时长约减半继续保留；本轮不再次修改其衰减参数。

## 先确认矩阵是否看见松开

修改前先用生产参数复现：12.288 MHz、CLK_DIV=768、SETTLE=3，
每行约 250 μs，每帧 1 ms，原稳定输入要求连续五帧相同的全矩阵状态。
36 组间隔/相位中，19 组原始帧已经看见空行，但稳定输入将其合并为直接换品。
1～4 ms 松开可能被五帧去抖吞掉；小于一帧的松开还可能根本没有被扫描采到。
证据为 `sim/temp/tail_lock_matrix_baseline_01/` 和其中的
`matrix_release_baseline.csv`。

现在另加每弦的松开观察：同一行连续两次采样为空，间隔一帧约 1 ms，
且该弦原来有稳定按品，产生一次 `release_event`。持续空行只发一次；
重新接触后允许下一次松开。此信号只用于演奏尾音锁定、准备空弦及取消颤音。
游戏使用的原 `row/raw/stable` 行为保留，逐时钟冻结对照通过。

测试中的全部 ≥2 ms 松开都可被此观察保留；单次空样本被拒绝。
1～2 ms 仍取决于扫描相位；扫描未采到的亚毫秒松开无法保证识别。
这是一项明确的输入分辨率边界，需要结合实体琴颈的实际接触情况试听。

## 本轮验证与边界

| 证据 | 覆盖 |
| --- | --- |
| `tail_lock_controls_01/tb_tail_lock_policy` | 30 项：准备/发声音高、真实重拨、连续滑音、空弦、短松开窗口、四弦独立、同拍拨弦优先、无补起音/硬释放 |
| `tail_lock_controls_01/tb_performance_vibrato_gesture` | 原 33 项颤音识别和取消条件，通过新策略接线 |
| `tail_lock_controls_01/tb_tail_lock_matrix` | 24 组间隔/扫描相位、四弦、12 组被原稳定去抖吞掉的松开现在被保留，4,079,712 时钟原矩阵全部旧输出相同，单空样本拒绝 |
| `tail_lock_audio_02` | 完整生产音频子链、物理矩阵列输入和生产手势时间；28,297 音频样本、28,296 次独立旧音源 PCM 对照、5 组真实拨弦 |
| `tail_lock_audio_gate_02` | 当前原工程实际完整音频子模块 VG 对照同一场景，28,297 音频样本、28,296 次独立旧音源 PCM 检查、5 组真实拨弦，通过 |

音频场景包括：第一品拨弦→3 ms 松开→第三品且无拨弦；重拨第三品；
重叠连续换品滑音；500 μs 单次空样本；长松开后准备其他品；空弦重拨；
四弦三次生产时长松按后的颤音；各弦独立取消和模式退出。
事件刺激仅在 ADC 已登记的拨弦/力度/待决输出边界，未强制矩阵、音符、DDS、相位或音频内部信号。
独立音高场景驱动冻结旧音源，逐完整 24 位 PCM 检查；门级另逐音频时钟比较
当前 RTL 的 16 位有效 PCM、两路串行音频六引脚、有效/时钟节拍/模式/握手/扫描行。
没有 SDF 回标，物理时序由同一完整原工程的新 P&R/STA 独立检查。

`tail_lock_audio_01` 的失败来自参考场景遗漏原有退出模式时的可闻音高锁存，
仅修正测试参考的模式切换任务后在 02 通过；生产 RTL 未因此改变。
`tail_lock_audio_gate_01` 在编译时因测试复制器误改 include 文件名而停止，
仅修正复制器后使用独立 02 目录，旧失败记录保留。

未重复 UI/UART/MPU 和其他无关的已完成仿真。171 个其余源码/ROM/工程/约束
哈希保留。新综合对部分未改模块进行了端口重命名和 LUT 重映射，
`unchanged_graph_audit.json` 如实保留 `REVIEW_REQUIRED`：仅 ADC 已证明原语图完全相同，
其他模块不宣称综合网表等价，不用旧日志认证本次新网表。
`source_reuse_audit.json` 只证明源码复用边界；本次新音频门级和完整新 STA 提供受影响链路的验证。
