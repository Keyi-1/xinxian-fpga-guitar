## 模型和存储

保留四独立声部、每声部八个模型、共32个模型状态。原来开启五度后最低和声模型是约3倍频，缺少实际的约1.5倍频低音，因此不能只增加现有高次成分的增益。

关闭五度保留旧频率 `[1,2,3,4,3,4,5,6]`、旧容量和旧混合增益。开启后前四个模型构成根音主体 `[1,2,5,7]`；后四个使用原七半音频率源的 `[1,3,4,5]` 倍，约为根音的 `[1.4983,4.4949,5.9932,7.4915]`。第4号模型具有自己的指针、低通、直流和延迟区，直接发出五度基频。

总计恰好1024个18位字/声部，四块延迟 BSRAM 不增加，上下文 DPB 也不增加。原来第4号模型只有112字，改为约1.5倍频会超过容量并被静音；本版将其扩为224字，同时重新分配其余区域。关闭五度仍使用原1020字布局。

音域分析采用真实64段倒数表和固定点取整，遍历覆盖频率区间内的全部倒数输入量化格，包含 D3～G5 和 `DEPTH_Q15=380` 的完整保守颤音范围。最低根音约145.130Hz，最高根音约793.110Hz；最高模型约5941.615Hz，仍在原6kHz有效上限内。模型6容量余量最紧，已经计入颤音，不能继续缩短。具体数据在 [range_report.json](../build/ks_fifth/audition_v2/range_report.json)。本次没有扩展最低音；低于上述范围不能沿用本容量承诺。

两种布局切换时，会重新激励该声部全部八个循环，清除旧指针/滤波状态的使用，避免把旧区域内容当作新弦状态。正式音源本来在起音时锁存五度开关；核心还额外防护了不伴随起音的直接模式变化。声部之间仍独立。

## 增益和时序预算

推荐 V2 的根音权重为 `[128,48,8,4]`，五度权重为 `[80,16,8,4]`。根音基频保持128，新增五度基频80；该模型的混合系数比根音主模型低约4.08dB，其他高次层减轻。这是系数之比，实际音量还取决于独立激励、衰减及泛音。原主链五度模式的 `(x>>>1)+(x>>>2)` 增益保留。权重总和296经该增益后约222，小于256；对16位模型输出而言，单声部理论峰值约28416/32768，试听不使用限幅掩盖削顶。四声部总混音仍由既有后级处理，该界限只针对单声部 KS 输出。

另保留 V1“和声突出”试听：只将五度主模型系数从80提高至96，其余模型、激励、布局和根音完全相同。其主模型系数相对根音为约−2.50dB，单声部理论峰值约29952/32768。两版均不做分段归一化，可以直接比较。

混合增益采用移位/加法，不增加乘法器；两个寄存级在已有四字上下文写回期间完成，避免新增三项求和直接串进旧累加关键路径。7倍根音以既有低/高半字加法链完成 `8f + ~f + 1`，避免额外32位组合减法链。

试听阶段先检查 RTL 固定周期预算、真实100MHz PLL下四声部48kHz调度、地址和量程；用户确认后再完成本次综合/P&R。时序验收采用上方本次实际报告，未使用旧版 Fmax 认证本次变更，也未放宽50/12.288/100MHz约束。

## 试听与验证

`tools/check_ks_fifth_audition.py audition_v2 --fifth-gain 80` 编译当前生产 KS RTL，以及按上一成功发布源清单冻结的参考。三个候选实例只在编译期分别选择根音、五度及全混合输出，全部八模型始终计算；不是软件合成或复制一个输出冒充多模型。V1 源副本、仿真结果和试听冻结在 `build/ks_fifth/audition_v1/`，不以其哈希认证当前 V2。

试听顺序是 D3、A3、A4、G5。每个音依次为 **根音单独1.5秒 → 五度单独1.5秒 → 两者合奏1.5秒**，段间0.2秒静音。三个部分取同一次、同年龄、同种子的拨弦样本。主链五度0.75增益在 Verilog 中执行，主机只将实际 RTL 样本按 `/256` 转成48kHz/16bit WAV并排列顺序，没有分段归一化、滤波或软件混音。

该试听是 KS 干声，不含整机力度包络、混响等后级效果，也不是板上 DAC 录音。另提供“原关闭五度 → 新合奏”的比较文件，用于检查根音主体和整体音量。

试听入口：

- [下载推荐V2试听](../build/releases/touch_game/ks_fifth_v2_20261101.zip)：包内 `root_fifth_together.wav` 为根音单独 → 五度单独 → 两者合奏。
- 同包 `off_vs_new_mix.wav` 为原关闭五度 → 新合奏。
- V1五度更突出的备选仅作为本机历史试听保留，未选作正式位流。

试听证据为 [V2 记录](../build/ks_fifth/audition_v2/verification.json)，其中等待听感确认的字段是当时的冻结记录；用户后续确认已写入本次正式认证。额外四声部整合对照在 `build/karplus_strong/fifth_tdm_v2/`；完整最终状态以 `build/ks_fifth/CURRENT_STATE.json` 和正式认证为准。

两版 RTL 试听、四声部整合验证及本次正式构建均已通过，当前没有运行中的仿真或构建：

- 关闭五度与上一成功源的288256个 PCM 逐值相同；另288256次根音与五度之和等于完整 RTL 混合。八个状态均持续更新且非静音，区域不重叠，四次不带拨弦的布局切换安全。
- V2 与 V1 的根音及关闭五度输出288000样本逐值不变，仅调整五度主模型系数。V2 四个测试音的五度音高误差绝对值均小于0.2音分；单声部实际混合峰值最高约11013/32768。
- 20～300ms 整体 RMS 的五度/根音比依次为 D3 −4.362dB、A3 −2.249dB、A4 −3.318dB、G5 −1.209dB。此项包含泛音，不能等同于基频谱峰之比，也不代替实际听感确认。
- 单声部计算等待最大176个100MHz时钟，四声部计算本体约7.04μs，对应48kHz采样周期约20.83μs；此外真实 PLL、CDC 与完整声部核心的整合测试比较55996个声部 PCM，输出延迟一致、无采样截止时间溢出。此项功能调度预算和上方实际布线 STA 分别验收，二者均通过。

试听仿真应用错误/警告为0；整合仿真错误为0，仅4条已知厂商 PLL 模型警告。[构建前源文件、参考和回退检查](../build/ks_fifth/preservation_check.json) 已通过。正式资源报告进一步确认 BSRAM118/118，与此前成功版本一致。关闭五度的原有布局/增益不变证明来自本次候选对冻结成功源的比较，不以旧KS等价日志认证新五度算法。未变的纯钢琴/哇音与滑音路径仅在源字节一致时复用原测试。
