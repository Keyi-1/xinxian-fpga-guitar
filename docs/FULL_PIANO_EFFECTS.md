## 按键与声音行为

| 按键 | 操作 | 功能 |
| --- | --- | --- |
| USER_BUTTON1 | 短按 | 钢琴 → 明亮弦音 → 钢琴，循环 |
| USER_BUTTON2 | 短按松手 | 合唱开／关 |
| USER_BUTTON2 | 按住约 1 秒 | 自动五度和声开／关，松手不触发合唱 |
| USER_BUTTON3 | 按一次 | 无效果 → 延音 → 轻量混响 → 无效果，循环 |

上电默认钢琴、合唱关、无效果、和声关。两套音色使用相同的音符表与基频，
通过采样域渐变切换；明亮弦音由原明亮／rock 系数归一化及独立分量衰减构成，
V2 已放慢明亮弦音原先过快的额外衰减。钢琴的八个实测模态与击弦起音参数保持成功版，
默认无效果的钢琴 PCM16 与 V1 逐样本相同。

第三键三个状态互斥：

- **无效果**：无新增延音或可听的 FPGA 房间回声；合唱和和声由第二键独立决定。
- **延音**：击弦起音的前 2048 样本（约 42.67 ms）保持原速，之后自然包络推进速度为普通状态的 1/4，
  空弦也会延长。明亮弦音的分量衰减同时放慢四倍。松开最后一个品位后保持阻尼系数，
  自然包络仍会衰减；退出延音后已释放声部恢复普通阻尼。振荡器相位保持 48 kHz 正常推进，音高不变。
- **轻量混响**：公共三条反馈延迟线，31.0／41.5／56.5 ms；输入为左右平均值的 3/8，反馈 5/8。
  混响开启时为 3/4 干声加两条各 1/8 的回声，关闭时保持原来的 7/8 干声。
  切换约 5.33 ms 渐变，延迟持续填充并保护未初始化 RAM；启用混响不启用延音。

**合唱**由第二键独立控制：左右声道使用反向调制的 15～23 ms 分数延迟，调制约 0.55 Hz；
开启时 3/4 干声加 1/4 延迟声，关闭时精确旁路。其变化是声像和轻微厚度／晃动，
混响增加空间回声，延音延长音符本身，三者使用不同处理。

自动和声为每次拨弦额外生成**高七个半音的纯五度音符**，Q20 比率为 1571089。
开关在每根弦的下一次真实拨弦时锁存；已发出的音符自然结束。
例如 C4 同时带出 G4，E4 带出 B4。当前没有调性识别或自动三度和弦推断。
整体增益保留余量，和声音符使用主音一半的模态幅度，避免开启后过载。

## 32／128 容量的含义

之前成功的物理钢琴工程是 4 × 8 = 32 个主要模态，三个效果输入固定为关闭；
旧的 32 分量谐波 FULL 没有默认采用这套钢琴音源。
本轮 `full_guitar_top` 默认 `USE_PIANO=1, PIANO_MODES=32, PIANO_CONTROL_ENABLE=1`。

每个声部独立保存 32 个 DDS 相位与分量衰减状态。四个声部并行处理各自分量，
单个 48 kHz 帧总共最多 128 个逻辑分量。钢琴使用八个实测主要模态，其余槽位为零；
明亮弦音已验证全部 32 个槽位产生非零幅度。超过 Nyquist 的分量会被静音，避免折叠。
开启和声后每根弦分配 **16 个主音槽位 + 16 个五度槽位**，总预算仍为 32，
四弦总预算仍为 128。钢琴模式此时为主音八个、五度八个有效模态。
击弦残差是短 ROM 播放，属于起音处理；容量数字指上述模态／谐波振荡器数量。

实测数字调度：四声部 128 个非零分量，连续 2,000 个真实 48 kHz 帧，
音源每帧计算 231 个 12.288 MHz 时钟，预算 256。加入音效、转换与串行输出后，
FULL 连续 10,000 帧仍无丢样、deadline miss 或显示 CDC 溢出。

## 板级实现与数字证据

下表及本节 74 项／3263 帧数字为三键初版 V1 的历史结果，
当前 V2 的重新构建结果见 [V2 验收记录](evidence/full_effects_v2_acceptance.txt)。

音频工程沿用 J13 矩阵、J8 ADC、V13 音频时钟和 PT8211 原接线。
三键为 AA13、AB13、Y12，均 Bank 9 / LVCMOS15 / 内部上拉；
这是本工程按用户 1～3 顺序的端口命名，官方旧示例的 key0/key1/rst_n 命名各有不同。
28 个物理端口全部有唯一球位，未增加外部接线。上电内部初始化约 21 µs，无复位键。

## 本轮上板检查

1. 下载 `neo_guitar_audio_full.fs`，检查上电无噪声、按品静音、拨弦发声、四弦并发及换品滑音。
2. 短按 1 键两次：钢琴、明亮弦音、钢琴循环，检查基音一致和切换平滑。
3. 短按 2 键开／关合唱，保持第三键“无效果”便于听辨。
4. 按 3 键进入延音，用同一力度拨空弦，间隔 3～4 秒比较尾音；再试拨弦后松品。
   再进入轻混响，确认出现公共空间回声；再按回无效果。
5. 长按 2 键约一秒，松手后合唱状态应不变；重新拨 C，检查同时有高五度 G。
   再次长按并重新拨弦，检查和声关闭。每一步同时观察四个状态 LED。
6. 分别用耳机与双扬声器检查单音、三音、四音和较快重拨。LCD 单独留待采购后验收。
