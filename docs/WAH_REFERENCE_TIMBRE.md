2026-10-05，音频版本 `6a790f8` 已进入 master，用户已认可 V4 延长衰减后的实物听感。
开发分支为 `feat/rock-metal-timbre`。第三音色已替换为新上传的 C4、E4、G4、
C4/E4/G4 合音参考。**当前生成和播放不使用旧重金属录音、V2 的 tanh 过驱动、基音增强或谐波滚降。**
V4 在 V3 基础上放慢包络衰减，延长尾音；全部模态、增益、相位和包络 ROM 保持逐字一致。

## 四份录音的实际特征

文件直接位于 `T:/Downloads/*哇音.wav`，44.1 kHz、PCM16、立体声。四份均不同，
每份检测到两次起音；用户设置为压缩／高音／低音／回声 0、混响关闭。
左右声道相关系数约 0.997～0.999。来源 SHA 和起音时间见 `build/wah_reference/analysis.json`。

这些录音不是只有整数倍谐波。它们有明显的 0.5、1.5、2.5、3.5 等半整数倍模态：
E4 有约 493、823、1154 Hz 强峰，G4 有约 586、1372 Hz 强峰；其中一些强于按键对应的音频率。
因此旧版纯整数谐波模型会漏掉重要的音色成分。初次按整数网格计算的“残差”，
大部分属于这些半倍频分量，不能将其直接当成宽带噪声。

起音后 0.05～0.65 秒的统计：

| 参考 | 3～12 kHz 能量占比（总能量取 100 Hz～16 kHz） | 半倍频网格外残差 |
| --- | --- | --- |
| C4 两次 | 5.11%／5.84% | 1.21%／1.35% |
| E4 两次 | 8.26%／7.38% | 0.76%／0.67% |
| G4 两次 | 5.86%／6.19% | 2.65%／2.79% |
| 合音两次 | 约 9%～10% | 以三个单音的功率谱组合另行检查 |

高频在起音后先增强、再改变分布。只取一张平均频谱会丢掉这种“哇”的运动。
分析工具因此提取每个分量的时间包络和相位，并分别保留三个音区。
采用六次单音的归一化能量排序，选出 32 个模态，覆盖各参考可识别半倍频网格能量的
99.24%～99.998%；这不是对全频谱逐样本复刻的声明。
合音的 25 Hz 功率谱分箱非负混合拟合相对残差约 0.306；自由增益允许人工力度差异，
残差本身不能唯一确定库乐队内部的处理算法。

## FPGA 实现

仍用四声部，每声部最多 32 个模态；相位数量没有增加。
频率比为实测半倍频网格的 32 个主要位置，基音槽位保持 1；
音符表不移调，但第三音色包含参考中存在的低八度分量。
其余槽位按能量排序，让自动五度和声的 16 主音 + 16 和声预算也优先保留主要特征。
超出 Nyquist 的分量继续静音。

三个参数库分别来自 C4、E4、G4 的两次单音。每次单音只做一次整体力度归一化，
保留包络运动；新声音不再强制基音最大，也不叠加旧版的人造削波或低通形状。
三库使用原有音区选择边界，在新拨弦时确定音区，随后保持相位连续。

每个模态存 32 个包络观察点，间隔 1024 个虚拟包络样本，按样本线性插值。
ROM 共 3072 个 25-bit 字，包含 12-bit 幅度与 13-bit 有符号差值。
FPGA 只将差值绝对值放进无符号乘法器，再用逻辑施加正负号和向下取整，
避免先前出现过的 Gowin 有符号 DSP 前加器缩位问题。
同一额外乘法器分时完成包络插值及 32 样本起音，**每声部只增加一个 DSP，调度仍为 233／256 时钟**。
时间地址先饱和再缩位，尾音不会回绕。

参考录音是按住琴键后人工松开。项目仍由右手拨弦触发，因此保留有限的干声：
ROM 内共同自然衰减时间常数仍为 0.25 个虚拟秒，0.45～0.60 个虚拟秒平滑收尾。
V4 播放时保留前 2048 样本（42.67 ms）原速，然后只有哇音包络按半速推进：
`wah_age = age < 2048 ? age : 2048 + floor((age - 2048) / 2)`。
因此后段实际时间常数变为约 0.5 秒，无效果自然尾音终点约为 1.157 秒，
平滑收尾约在 0.857～1.157 秒。频谱运动也随包络减速，模态频率与相位推进不减速，音高不变。
32 样本起音与最初 2048 个输出样本保持 V3 原样。
仅用移位、加法和比较实现，不增加 RAM、DSP、相位槽位或每样本计算时钟。
各高频分量使用自己的实测运动，没有旧版单独过快的高次谐波衰减。
开启延音后，原有 age 仍在前 2048 样本之后按四分之一速度推进；
与 V4 哇音半速映射叠加，包络后段为实际八分之一速度，尾音终点约为 4.501 秒。
这些时长适用于空弦或未松品的自然衰减；无效果下松品仍应用原来的阻尼，重新拨弦仍重新起音。
音效键关闭时没有混响尾音；轻混响、合唱及自动五度和声的控制方式沿用原工程。

`mem/rock_*` 与 `rock_select` 的名字保留以兼容第三音色接口，当前内容已全部改为新哇音参考。
参数准备工具是 `tools/analyze_wah_reference.py`、`tools/generate_wah_assets.py`；
旧名生成入口只是调用新工具，运行时不读取旧 WAV。

## 数字验收与实际试听

完整 80 项回归通过。独立整数模型比对 212000 个样本，包含三个音区完整的延长干声寿命，
正／负斜率插值、六种音高、四种力度、Nyquist、五度、延音、音色渐变与重新拨弦。
原钢琴／明亮弦音 12000 点及原钢琴击弦 32000 点仍逐样本一致。
128 非零分量预算、完整尾音及地址边界检查通过。
门级 DAC 核对结果和文件 SHA 见 [V4 验收记录](evidence/wah_long_decay_acceptance.txt)。
6528 个实际 DAC 音频帧与 RTL 逐位一致，其中 1597 帧覆盖哇音进入半速包络后的输出。
此前 V3 的验收记录作为历史版本保留。

以下是实际 256 时钟预算的 RTL、板级声像、音效及 PCM16 导出；没有软件加效果或归一化：

- `build/wah_reference/rtl_wah_long_dry.wav`：11 秒，无混响；C4、E4、G4 单音，三音合音两次，最后 G3/C4/E4/G4 四音。各次拨弦之间留出完整自然衰减，不发送松品事件。
- `rtl_wah_long_room.wav`：同一输出，另开轻混响，供音效对照。
- `rtl_wah_long_dry_sustain_comparison.wav`：C4 不松品，先 5 秒无效果，停顿 0.25 秒，再 5 秒仅延音。
- `rtl_wah_v3_v4_dry_comparison.wav`：先旧 V3 C4 干声 3 秒，停顿 0.25 秒，再新版 C4 干声 5 秒。力度和声像一致，不做归一化。
- `rtl_wah_long_spectrum.png`：新 C4 参考与实际输出频谱；`rtl_wah_long_decay.png`：旧干声／新干声／新延音衰减。

实际干声 C4／E4／G4 的 3～12 kHz 能量占比为 **4.38%／2.92%／5.48%**（起音后 0.05～0.35 秒）。
模态增益表没有改变；包络与频谱运动减速，使固定实际时间窗中的能量占比与 V3 不同。
相同 C4 窗口中，被替换 V2 的高频占比只有约 **0.000768%**；因此这次确实保留了原先缺失的高频。
按键对应频率峰约为 261.658／329.590／392.029 Hz。
无效果最大 PCM16 为 3582，轻混响为 3093，均无削顶。
C4 干声的晚窗 RMS 比早窗低 24.23 dB，延音仅低 4.06 dB；最后非零样本分别在 1.15733／4.50038 秒。
早窗为 50～100 ms，晚窗为 1000～1050 ms，两者最初 2048 个样本逐位相同，
也分别与备份 V3 的最初 2048 个输出样本逐位相同。
在相同的 500～550 ms 窗口，新干声 RMS 为 225.57，V3 为 40.72，约增至 5.54 倍。
