## 连接与行为

- “曲目编号＋模式”由同一条命令跨时钟传递，数据在确认前保持不变。
  普通游戏与试听使用同一份目录和静态 ROM，启动锁定元信息。
- `game_p2_mode_router` 在采样边界禁止新起音、强制释放旧声，等所有声部静音后确认命令并应用推荐音色。
  推荐音色真正加载到 `guitar_effect_buttons` 的音色状态，原按键仍可继续切换三种音色。
  合唱、五度和声、延音／混响状态和音色参数不变。
- 新的游戏代数用于识别重玩后的新快照，结果页的旧故障／结束状态不会立即取消新一轮。
  核心 fault 自动走强制释放；布局异常通过 UI 退出到结果页，显示 ERROR。
- 256 bit 帧快照保存 32 位曲时／得分、16 位统计、64 bit 消费环、窗口头和代数。
  音频侧提交窗口头与消费位；显示侧继续共享 CDC 的帧保持 bank。
- 显示扫描最多 64 条窗口事件。复用一个 18 位常数除法器生成坐标和尾长；
  对尾长先钳制至 80000 样本，与原 `min(duration/250,320)` 一致。
  有效像素仍使用原四级流水线、六个系统时钟／像素和 x=96 判定线。
- 字库为 114 个常规字符＋12 个原标题 tile，仍在原 2048×16 bit 容量内。
  游戏得分显示六位，结果计数显示五位，不在 255 或 999 时回卷。
  进度条按各曲实际总时长更新；帧中间不改状态。
- 曲谱采用明确的 DPB16 切片和逐行生成的 INIT 常量，逻辑上保留完整 2048×96 bit。
  独立单元为 12 块；生产综合删除未用的分组字段后，实际为 **10 个 BSRAM**。
  音频与显示两读端口各为一拍同步读，静态只读，无运行期写入或读写冲突。
  整机 BSRAM 数量以下方完整 P&R 为准。

### P2 快照布局

| 位 | 内容 |
|---|---|
| 63:0 | 消费环，按全局事件 ID 低六位索引 |
| 95:64 | 32 位采样曲时，倒计时为补码负数 |
| 127:96 | 32 位得分 |
| 143:128 / 159:144 | 连击／最高连击，各 16 位 |
| 175:160 / 191:176 / 207:192 | Hit／Miss／Wrong，各 16 位 |
| 219:208 / 227:220 | 四轨判定／四轨判定代数 |
| 229:228 | 模式，0菜单、1演奏、2游戏、3试听 |
| 230 / 231 / 232 / 233 / 234 | 倒计时、结束、切换、fault、deadline |
| 237:235 / 249:238 / 255:250 | 当前曲目、窗口头、游戏代数低六位 |

未被生产显示消费的位允许被综合删除；统计、消费及判定的 RTL 契约不变。
P1 控制器和默认兼容参数仍用于旧回归，生产顶层 `USE_P2=1` 实例化上述完整连接。
