# FULL 音效 V2：空弦延音与可区分的合唱／混响

后续三音色更新见 [ROCK_TIMBRE.md](ROCK_TIMBRE.md)；本页记录 V2 两音色的音效基线。

日期：2026-10-05，分支 `feat/full-piano-effects`。
用户已上板确认三键功能正常，但反馈三种音效区别小，尤其明亮弦音的空弦延音不明显。
V2 使用相同的板级入口、接线、按键与音符表，重新实现效果参数和延音行为。

## 原因与修改

V1 延音只放慢松品之后的阻尼，空弦没有这个事件。
同一次空弦 C4 拨弦的实际 RTL PCM16 对照证明：两种音色的 V1 延音与无效果输出完全相同。
明亮弦音又叠加了很快的逐分量衰减，因而更快消失。合唱使用约 1 ms 的相同左右调制，
主要改变梳状滤波音色，缺少空间宽度；混响每条回声只有 1/32。

| 处理 | V2 实现 | 比较时关注 |
| --- | --- | --- |
| 延音 | 击弦起音前 2048 样本保持原速；之后自然包络每四个样本推进一次；松品后保持阻尼系数 | 空弦及按品音符本身的长尾音 |
| 明亮弦音 | 普通状态每四个样本更新分量衰减，延音状态每十六个样本更新 | 尾部不再被额外衰减迅速压掉 |
| 合唱 | 15～23 ms 的 Q8 分数延迟，0.55 Hz 三角调制；左右反向；3/4 干声加 1/4 延迟声 | 左右宽度、厚度与缓慢晃动 |
| 轻混响 | 31.0／41.5／56.5 ms 公共反馈延迟；3/8 归一化输入、5/8 反馈；3/4 干声加两条各 1/8 回声 | 起音后的空间反射，反馈尾音约 0.6 秒 |

延音只改变包络和分量幅度衰减，DDS 相位仍按正常 48 kHz 采样推进。
退出延音时已松品的音符恢复普通阻尼。自然包络仍会结束，没有无限维持平台。
房间网络的输入系数与反馈系数之和为一，反馈小于一；干湿系数之和为一。
分数延迟使用两条独立的注册凸组合乘法，避免以前 Gowin 有符号预加器的问题。
延迟 RAM 有填充保护，按键切换保留约 5.33 ms 的干湿渐变。

默认无效果的钢琴 **192000 个 PCM16 立体声帧与 V1 逐样本相同**。
原固定八模态钢琴入口的 32000 个样本也与独立参考相同。

## 试听与量化

`build/piano/effects_v2` 有 16 份原始输出 WAV、两份 V2 效果顺序试听、两份 V1→V2 延音对照，
以及 `effects_metrics.json` 和 `open_string_effects_comparison.png`。
WAV 为实际 RTL 输出的 48 kHz 立体声 PCM16，没有归一化、额外混响或软件音效。

- `v2_piano_effects_comparison.wav`：无效果 → 合唱 → 轻混响 → 延音。
- `v2_bright_effects_comparison.wav`：同样顺序，使用明亮弦音。
- 每段 4 秒，间隔 0.35 秒；起点为 0、4.35、8.70、13.05 秒。每段只有一次相同 C4 拨弦。
- `piano_sustain_v1_v2.wav`、`bright_sustain_v1_v2.wav`：先 V1，后 V2，各 4 秒。

拨弦后 1.5～2.0 秒，V2 延音比无效果的尾部 RMS：钢琴 **+18.21 dB**，明亮弦音 **+26.68 dB**。
两个音色的无效果／延音基频峰均为 **261.658 Hz**，接近目标 C4 的 261.626 Hz；FFT 网格间隔约 0.183 Hz。
去除最佳拟合音量差后，混响相对干声的残差 RMS 从约 10～12% 提高到约 21%；
合唱左右相关系数由近 1 降至约 0.88。这些数字证明处理差异，听感仍以实际耳机／双扬声器为准。
