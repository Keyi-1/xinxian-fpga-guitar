# 四弦拨弦渐变、150×150 莉萨如和环形真实频谱

这是独立的下一版上板工程，Top=`neo_guitar_radial_top`，
器件 `GW5AT-LV60PG484AC1/I0`，Device B。
旧的 `neo_guitar_lissajous` 居中版本及其位流继续保留。

## 画面与演奏

480×272 屏幕左侧为 208×272，四条带各 68 像素：第一弦蓝、第二弦绿、第三弦橙、第四弦红。
只有实际接受的拨弦事件才使对应条带快速点亮，之后约 0.58 秒渐暗；
四弦可同时亮起，重拨重新提亮，单独换品不会伪造拨弦。
每条带显示弦号、品位和当前实际发声音高，保留原 20 ms 滑音与松品/延音策略。

右侧为 272×272，中心在像素中心 **(343.5,135.5)**，即约 (344,136)。
莉萨如绘图区为 **150×150 原生像素**，中心和 X/Y 半径分别为上述中心及 74.5。
圆半径约 106，与 150×150 正方形的对角线相匹配；谱柱从半径 107 向外伸展，
柱体最高半径 134，峰值标记最高到 135。所有内容均在屏内。
圆内保留细线、抗锯齿、光晕和淡残影，四音曲线叠加混色。
Y 轴为 220 Hz 参考，X 轴来自四根弦真实主音高 DDS；它不是全部模态 PCM 的 XY 混合。

12 点附近为最低频率，顺时针升高。64 根可视柱来自 32 个实际频带的插值和邻域平滑，
快速上升、每帧缓降，另有慢速峰值标记和沿半径变亮的彩色渐变。
低频段不分配没有 FFT 格点的空频带；实际无能量的区域可以为空，静音会回落。

## 真实频谱与资源共享

分析输入为既有 `guitar_audio_top.final_pcm_valid/final_pcm`：
最终音效后的左右 PCM24 平均值，包含原三音色、五度和声、合唱及混响。
这是单声道混合频谱，两声道相位抵消会影响幅度，不等于两声道能量之和。

PCM 通过保持数据的请求/应答邮箱从 12.288 MHz 进入 50 MHz 域。
交接没有向音频施加背压；超限有独立诊断，仿真必须为零。
FFT 连续采集 1024 个 48 kHz 样本，加 Hann 窗；处理时短暂停止采集下一分析窗口，
不停止或丢弃实际音频输出。每个分析窗口约 22.2 ms。
FFT 保留既有分析定点算法，24→16 位只用于显示分析，音频 PCM 精度保持原样。
正频率覆盖 bin 1..512，约 **46.875 Hz..24 kHz**，排除 DC 并包含 Nyquist。
前 14 个频带各对应一个低频格点，后续频带逐渐加宽，避免低频空带。
幅度采用对数映射、有限增益与缓降参考，避免小噪声在静音时被放大成满圈。
32 个频带计算完成后整组发布；64 根柱及拨弦条带在帧消隐内更新。

一套 18×16 乘法器分时完成窗函数和四个复数乘积，不同时复制四个 FFT 乘法器。
FFT 用两个双端口工作 BSRAM 和一个窗 ROM，共 3 个 BSRAM。
曲线继续使用两条行缓存和一个正弦 ROM，共 3 个 BSRAM。
反正弦、旋转因子和小型径向表显式使用 `syn_romstyle="logic"`，避免自动占用 RAM。
原音频使用 112 个 BSRAM，总预算为 **118/118**，不能再直接叠加帧缓存。
新增共享只发生在显示/频谱模块，音源的 4×32 分量、ROM、定点精度和全部音效没有降低。

圆周方向用八分区阈值比较，距离用平方距离；显示不做逐像素除法或 atan2。
几何/字体为五级流水线，行缓存到 RGB 为四级，均在六个 50 MHz 时钟的像素周期内完成。
面板 RGB、同步与 DE 仍在 DCLK 下降沿输出，距上升沿约 60 ns。
绘图最坏 2266/3186 时钟（1632 行独立解析参考测试），无丢行。

不能直接增加帧缓存或提高显示时钟。

## 接线、按键与下载

沿用上一版所有接线：J5 LCD、J13 品位矩阵、J8 MCP3208、PT8211 和音箱。
**J17 必须可靠短接 1–2，确保跳帽接触牢固**；它关闭与 LCD 共线的 CH569。
不需要 HDMI。V22 仍为 50 MHz，V13 仍为板上已配置的 12.288 MHz。
三个用户按键保持原功能：

| 按键 | 功能 |
| --- | --- |
| KEY0 | 钢琴 → 明亮弦音 → 哇音 V4 |
| KEY1 短按 | 合唱开关 |
| KEY1 长按约 1 秒 | 五度和声开关，后续拨弦生效 |
| KEY2 | 无效果 → 延音 → 轻混响 |

在仓库根目录构建：

```powershell
gw_sh.exe gowin/neo_guitar_radial/build.tcl
```

Gowin IDE 可打开 `neo_guitar_radial.gprj`，确认 Top 为 `neo_guitar_radial_top`。
最终下载 `impl/pnr/neo_guitar_radial.fs`，首次使用 SRAM Program/Configure。
资源和两个时钟的 setup/hold 必须先由 `check_result.py` 验收，不能仅以生成了 FS 判断通过。
原屏背光恒流匹配和 GT911 触摸状态沿用上一版。
